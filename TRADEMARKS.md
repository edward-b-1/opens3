# Trademark policy

The name **OpenS3** and the OpenS3 logo (when there is one) identify this
project and the software released from this repository. The code is free
software under the AGPL-3.0-or-later (see `LICENSE`); this policy is about
the name, which the licence does not cover.

## What you may do without asking

- Refer to the software as OpenS3 in documentation, articles, talks,
  package listings and comparisons, including to say that something is
  "compatible with OpenS3" or "based on OpenS3".
- Distribute unmodified releases from this repository under the name
  OpenS3, including in container images and operating-system packages,
  as long as the source and the licence are as published here.
- Offer OpenS3 hosting, support, training or consulting, describing it
  as such ("hosted OpenS3", "OpenS3 support"), as long as the software
  you run is an unmodified release or your modifications are published
  under the AGPL as the licence requires.

## What needs permission

- Calling a modified version OpenS3, or a name that suggests it is the
  official project ("OpenS3 Enterprise", "OpenS3 Pro", "OpenS3 Cloud").
  Modified versions must use their own name and say what they derive
  from.
- Using the name or logo as your own product's brand, in a company name,
  or in a domain name that implies you are the project.
- Implying that the project endorses, certifies or supports your product
  or service.

Ask by opening an issue in this repository.

## Why this exists

The licence makes the code free to use, change and redistribute, and
requires changes to be shared back. The name is what tells users which
software they are getting. Keeping the two separate is what lets the
code be forked freely without a fork being mistaken for the project.
